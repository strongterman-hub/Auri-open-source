# 路线图

以下是方向与已知缺口，不是发布日期承诺。优先级按真实用户反馈调整。

## 优先：现有体验可靠性

- 分别观测主动消息生成、推送接受、系统展示、曝光与回复，减少无依据的打扰。
- 各 Android 厂商通知通道与真实设备回归。
- 验证事件提取、跨天时间理解、纠错合并和遗忘召回质量。
- 提高首次安装、邮箱收件、首次聊天和权限说明的可理解性。
- 核对健康来源覆盖、日界与睡眠评分缺失值处理。

## 自部署与社区

- 增加真实模型提供商的兼容测试及费用口径配置。
- 完善安装体验、依赖锁定与版本升级说明。
- 加强数据导出、删除、备份恢复与隐私反馈流程。
- 根据实际贡献情况改善模块边界和开发工具。

## 尚未实现或尚未完成验证

- 前瞻 intents 的通用条件触发执行；目前只有 CRUD。
- 日程与手机状态观察源的真实数据接入。
- 多 worker/多副本运行的一致性与任务协调。
- iOS、原生鸿蒙客户端。
- 面向各商店的主体、材料、支付和内容规则适配。
- 所有品牌设备或所有小米云地区的兼容承诺。

提出新功能时请说明使用场景以及它如何改善连续聊天、记忆或主动联系。避免仅为了功能数量引入新的复杂设置。
